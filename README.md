Exam Seating and Room Allocation System

About the Project

The Exam Seating and Room Allocation System is a Java-based application developed to simplify and automate the process of examination seating management.

The system allows administrators to manage student records, examination rooms, and examination details. It automatically allocates students to available rooms according to their seating capacity and assigns unique seat numbers.

The main objective of this project is to reduce manual work, save time, minimize allocation errors, and make examination management more efficient.

Features

- Add and manage student details.
- Display registered students.
- Add examination rooms and seating capacities.
- Manage examination details.
- Automatically allocate students to available rooms.
- Assign unique seat numbers.
- Display room-wise seating arrangements.
- Search student allocation using roll number.
- Prevent duplicate student and room records.
- Check room capacity and identify unallocated students.
- Save and load records using file handling.

Technologies Used

- **Programming Language:** Java
- **Data Structures:** ArrayList
- **Algorithms:** Sorting and Searching
- **File Handling:** Text File Storage
- **IDE:** Visual Studio Code

Project Concepts

This project demonstrates the practical implementation of Data Structures and Algorithms, object-oriented programming, classes, objects, methods, collections, and file handling in Java.

How to Run

1. Clone this repository.
2. Open the project in Visual Studio Code or any Java IDE.
3. Open the terminal.
4. Compile the Java file:

```bash
javac ExamSeatingSystem.java
```

5. Run the application:

```bash
java ExamSeatingSystem
```
